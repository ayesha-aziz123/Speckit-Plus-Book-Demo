Chatbot Integration Steps

Integrating a chatbot into your Docusaurus documentation site, powered by the Qdrant + FastAPI + RAG backend, significantly enhances user experience by providing an interactive and intelligent way to access information. This section outlines the key steps to achieve this integration.

1. Frontend Chatbot Component​

You'll need a React component that renders the chatbot UI within your Docusaurus site. This component will handle user input, display chatbot responses, and communicate with your FastAPI backend.

Example Chatbot Component (src/components/Chatbot.js)​

// src/components/Chatbot.js (Simplified Example)
import React, { useState } from 'react';
import styles from './Chatbot.module.css'; // Assuming you create this CSS Module

function Chatbot() {
  const [messages, setMessages] = useState([]);
  const [input, setInput] = useState('');
  const [loading, setLoading] = useState(false);

  const sendMessage = async () => {
    if (input.trim() === '') return;

    const userMessage = { text: input, sender: 'user' };
    setMessages((prevMessages) => [...prevMessages, userMessage]);
    setInput('');
    setLoading(true);

    try {
      const response = await fetch('http://localhost:8000/query', { // Your FastAPI endpoint
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({ query: input }),
      });
      const data = await response.json();
      const botMessage = { text: data.answer, sender: 'bot' };
      setMessages((prevMessages) => [...prevMessages, botMessage]);
    } catch (error) {
      console.error('Error fetching chatbot response:', error);
      setMessages((prevMessages) => [...prevMessages, { text: 'Sorry, I encountered an error.', sender: 'bot' }]);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className={styles.chatbotContainer}>
      <div className={styles.messages}>
        {messages.map((msg, index) => (
          <div key={index} className={clsx(styles.message, styles[msg.sender])}>
            {msg.text}
          </div>
        ))}
        {loading && <div className={styles.message}>Thinking...</div>}
      </div>
      <div className={styles.inputArea}>
        <input
          type="text"
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyPress={(e) => e.key === 'Enter' && sendMessage()}
          placeholder="Ask me about the documentation..."
        />
        <button onClick={sendMessage} disabled={loading}>Send</button>
      </div>
    </div>
  );
}

export default Chatbot;

2. Integrating the Chatbot into Docusaurus​

You can embed this Chatbot component into any Docusaurus page or even a custom layout. A common approach is to create a dedicated page or integrate it into a sidebar or footer component.

Option A: Dedicated Chatbot Page (src/pages/chatbot.js)​

Create a new file src/pages/chatbot.js:

// src/pages/chatbot.js
import React from 'react';
import Layout from '@theme/Layout';
import Chatbot from '@site/src/components/Chatbot';

function ChatbotPage() {
  return (
    <Layout title="Chat with our AI Documentation">
      <main style={{ display: 'flex', justifyContent: 'center', alignItems: 'center', minHeight: 'calc(100vh - var(--ifm-navbar-height) - var(--ifm-footer-height))', backgroundColor: 'var(--ifm-background-color)' }}>
        <Chatbot />
      </main>
    </Layout>
  );
}

export default ChatbotPage;

Then, add a link to this page in your docusaurus.config.js navbar items:

// docusaurus.config.js excerpt
navbar: {
  // ... existing items
  items: [
    // ...
    { to: '/chatbot', label: 'Ask AI', position: 'right' },
  ],
},

Option B: Floating Chat Widget​

For a more persistent chatbot experience, you might implement a floating widget that appears on all pages. This typically involves modifying a theme component (e.g., LayoutWrapper if you use @docusaurus/theme-classic and swizzle it) or a custom plugin.

3. Ensuring CORS for FastAPI​

When your Docusaurus frontend (running on one origin, e.g., localhost:3000) tries to communicate with your FastAPI backend (running on another origin, e.g., localhost:8000), you will encounter Cross-Origin Resource Sharing (CORS) errors. You need to configure CORS in your FastAPI application.

# main.py (FastAPI app) - CORS configuration
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

origins = [
    "http://localhost:3000",  # Your Docusaurus frontend origin
    "http://localhost:8000",  # If your backend also serves a frontend
    "*", # Or specify your actual Docusaurus deployment URL
]

app.add_middleware(
    CORSMiddleware,
    allow_origins=origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Your RAG endpoint as defined previously
# ...

4. Deployment Considerations​

  • FastAPI Backend: Deploy your FastAPI application to a suitable server (e.g., cloud VM, serverless function, Kubernetes). Ensure it's accessible from your Docusaurus site.
  • Qdrant: Deploy Qdrant alongside your FastAPI backend or as a managed service. Ensure connectivity and proper indexing of your documentation.
  • Docusaurus Frontend: Deploy your static Docusaurus site to a CDN or static hosting service (e.g., Netlify, Vercel, GitHub Pages).

By following these steps, you can successfully integrate a powerful, AI-driven chatbot into your Docusaurus documentation, making your content more dynamic and accessible.
