Docusaurus Setup

Docusaurus is a powerful static site generator that helps you build, deploy, and maintain documentation websites with ease. It's built with React, allowing for custom components and a highly flexible structure. This section guides you through the basic setup required for our AI-powered documentation system.

1. Initializing Your Docusaurus Project​

If you haven't already, you can create a new Docusaurus project using the official CLI tool. This will scaffold a basic project structure.

npx create-docusaurus@latest my-ai-docs classic
cd my-ai-docs
  • my-ai-docs: The name of your project directory.
  • classic: The default template, which includes a blog, custom pages, and markdown-powered documentation.

2. Project Structure Overview​

After initialization, your project will have a structure similar to this:

my-ai-docs/
├── blog/
├── docs/
│   └── ... your markdown documentation files
├── src/
│   ├── components/
│   │   └── HomepageFeatures.js
│   ├── css/
│   │   └── custom.css
│   └── pages/
│       └── index.js
├── static/
│   ├── img/
│   │   └── ... images, favicon
│   └── static assets
├── docusaurus.config.js
├── package.json
├── sidebars.js
├── README.md
└── ... other config files
  • blog/: Contains markdown files for your blog posts.
  • docs/: The heart of your documentation. All your markdown files for the book chapters will reside here, often organized into subdirectories.
  • src/: For custom React components (components/), custom CSS (css/), and custom pages like your landing page (pages/index.js).
  • static/: For static assets like images, logos, and favicons. These are copied directly to the root of your build output.
  • docusaurus.config.js: The main configuration file for your Docusaurus site. Here you define site metadata, plugins, themes, navbar, and footer.
  • sidebars.js: Defines the structure and order of your documentation sidebar. This is crucial for organizing your book chapters.
  • package.json: Standard Node.js package file, listing dependencies and scripts.

3. Basic Configuration (docusaurus.config.js)​

This file is central to customizing your Docusaurus site. We've already configured it for our book. Key aspects include:

  • title & tagline: Your site's title and a brief description.
  • url & baseUrl: Important for deployment and linking.
  • favicon: Your site's icon.
  • presets: Defines the core plugins used (e.g., docs, blog, theme).
  • themeConfig: Extensive options for customizing your site's look and feel, including navbar, footer, and color modes.

Refer to the previously created docusaurus.config.js for the specific setup with purple primary color and dark theme.

4. Defining Your Sidebar (sidebars.js)​

As seen in the sidebars.js file, this is where you define the hierarchical structure of your documentation. Each entry in the items array corresponds to a markdown file in your docs directory. The structure uses type: 'category' for dropdowns and direct markdown file paths for individual pages.

// sidebars.js excerpt
const sidebars = {
  tutorialSidebar: [
    {
      type: 'category',
      label: '01 — Introduction',
      items: [
        'intro/what-this-book-covers',
        'intro/why-ai-powered-documentation-matters',
        // ... more items
      ],
    },
    // ... more categories
  ],
};

5. Running Your Docusaurus Site​

To see your documentation site in action during development, use the following command:

npm run start

This command starts a local development server and opens your site in a browser, typically at http://localhost:3000. It also provides hot-reloading, so changes to your markdown files, React components, or configuration will automatically update the browser.

With Docusaurus set up, we have a robust foundation for integrating AI-powered content and features.
